How it works

intake → injection screen (ticket text is untrusted) → duplicate check (embedding similarity, in code) → one decision call: eleven typed questions (Choice / Score / Verify) answered as probability distributions by the engine behind the port (TypeSafe Jev, an LLM on a strict schema, or the offline rules) → composition in code (priority formula, routing matrix + overrides) → guardrails (completeness, distribution sanity, low-confidence forcing, safety flags) → agent gate. The model decides nothing consequential; code composes; the agent acts.
